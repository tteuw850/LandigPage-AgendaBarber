# Agenda Barber - Landing Page

Website com React, TypeScript e Vite, contendo celular 3D, pop-ups
e animacoes de scroll.

## Executar

- npm install
- npm run dev
- npm run build
- npm run lint

## Estrutura

Veja docs/PROJECT_STRUCTURE.md.
Os componentes React ficam em src/components; as paginas em src/pages;
os estilos em src/styles e os arquivos de imagem e video em src/assets.

Os backups anteriores foram mantidos em archive e em uma copia externa.
Os testes visuais anteriores foram mantidos em tests/qa. Deixe o servidor
Vite ativo antes de executar um teste visual.
